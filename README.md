### About Me

Cybersecurity researcher with hands-on experience in **Web Application Penetration Testing (WAPT)**, **Cyber Threat Intelligence (CTI)**, and **OSINT tool development**. I build custom offensive security tools, participate in CTF competitions, and actively hunt vulnerabilities through bug bounty programs. Passionate about automating reconnaissance workflows and creating intelligence platforms that make a real impact.

- Web Application Penetration Testing (WAPT)
- Cyber Threat Intelligence (CTI) & OSINT
- Bug Bounty Hunting & Vulnerability Research
- CTF Competitions & Offensive Security
- Security Tool Development & Automation
