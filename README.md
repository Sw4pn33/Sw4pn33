### `> about --me`

Security researcher and tool developer focused on **Cyber Threat Intelligence**, **web application security**, and **OSINT automation**. I build platforms that surface adversary infrastructure, track dark web activity, and attribute threat actors — then ship the tooling as open source.

- Threat intelligence platforms & attribution graph tools
- Web application security research & bug bounty programs
- OSINT automation & dark web monitoring pipelines
- CTF competitions across web, pwn, and forensics
- Custom recon frameworks and data visualisation tools
